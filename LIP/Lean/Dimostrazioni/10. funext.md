`funext` rappresenta la Function extensionality: `(∀ x, f x = g x) → f = g`.

Quando il goal è un’uguaglianza **tra funzioni**, `funext n` fa due cose:

1. introduce un input arbitrario `n`, come fa `intro`;
2. cambia il goal da `f = g` a `f n = g n`.

``` lean
--date le funzioni:
def composeN (f g : Nat → Nat) : Nat → Nat :=
  fun n => f (g n)
  
def idN : Nat → Nat := fun n => n

--esepio dimostrazione con funext:
theorem composeN_identity_left (f : Nat → Nat) : composeN idN f = f := by
  funext n
  rfl

```
